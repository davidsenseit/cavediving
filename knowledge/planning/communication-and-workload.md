# A message needs shared meaning

## Core idea

A gesture is useful only if the receiver can perceive and interpret it. Confirm the team’s hand, light and tactile communication within its training. Added tasks consume attention; a survey or camera objective must not displace awareness of gas, route, teammates or position.

## Original example

A photographer repeatedly misses a teammate’s communication. Treat this as a workload and communication problem, not proof that the message was understood.


## Check understanding

Explain the assumption most likely to make the example unsafe if ignored.

## Learning objective
Explain how perception, meaning and confirmation can fail separately.

## Follow the message
The sender needs a signal the receiver can perceive, a meaning both understand, and the expected acknowledgement. A light signal can be missed when attention is directed elsewhere. A visible hand signal can still be misunderstood. Repeating a message does not establish understanding.

Brief hand, light and touch contact communication for the actual team. Loss of visibility changes which channels remain usable; a written message still requires seeing and reading it. Touch contact is a trained communication and team-control skill, not a universal set of gestures inferred from a description.

## Compare cases
A teammate does not look toward a signal: receipt is uncertain. A teammate looks but responds with an unexpected action: meaning is uncertain. A familiar acknowledgement helps establish shared understanding, but continue observing whether team actions match the message.

## Debrief with observations
Replace 'communication was poor' with the observed event, what each diver believed, and what information was missing. Ask how workload affected receipt and how the team could recognize the mismatch earlier.
