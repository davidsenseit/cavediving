# Match equal capacities and equal starting pressures

## Prerequisites

GAS-006 and GAS-007: entry fractions and retained thresholds.

## Learning objective

Use the simplest two-diver case to explain entry use, retained supply and the two possible donor checks.

## Declare the classroom model

Both divers have equal stated exit demands. For this comparison only, each ordinary exit demand is stipulated as one third of that diver's starting inventory. These are supplied bounds, not demands predicted from the route or measured breathing. The failure is complete loss of one diver's supply; all remaining donor gas is assumed accessible and deliverable. No separate residual pressure, delay, stress or decompression allowance is included. This deliberately limited allocation model is not a real-dive reserve validation.

## Worked example

Both divers have 24 L at 240 bar. Each starts with 5,760 reference L. A thirds entry allowance is 1,920 reference L = 80 bar, giving a 160 bar turn.

| Failure | Donor quantity at its threshold | Stipulated combined exit demand | Surplus |
| --- | --- | --- | --- |
| B loses gas; A donates | 24 × 160 = 3,840 reference L | 1,920 + 1,920 = 3,840 reference L | 0 reference L |
| A loses gas; B donates | 24 × 160 = 3,840 reference L | 3,840 reference L | 0 reference L |

Equality is sufficient only for the stated arithmetic comparison; it provides no additional margin. Matching hardware and starting pressure do not establish equal breathing demand in life.

The team turns when the first diver reaches their applicable threshold, or another limit is reached. Do not assume both gauges reach their thresholds simultaneously.

## Guided calculation

Repeat with two divers each using 20 L at 210 bar. Keep the stated model unchanged. Calculate inventories, entry allowances, turn pressures and both donor checks.

## Guided answer — reveal after the learner attempts

Each starts with **4,200 reference L**, with a 1,400 reference L = 70 bar allowance and **140 bar** threshold. Each retains 2,800 reference L. Stipulated combined demand is 2,800 reference L, leaving zero surplus in either donor check.
