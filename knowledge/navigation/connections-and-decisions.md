# A connection and a route decision are different

## Terminology

Read the relevant definitions in [GLOSSARY.md](../../GLOSSARY.md) before assessment.

## Core idea

A T-junction has three already connected guideline branches and asks which branch leads back to the team's exit. A break in the line adds a separate problem: maintaining an uninterrupted physical reference.

In these entries, a jump is a temporary connection from a route line to a separate branch line; a gap connects separated ends along a route. Confirm terminology during the team briefing because local usage can vary. Both require suitable line connections and exit identification within the diver's training. Seeing the next line is not a connection.

## Original example

A side-passage line begins within sight of the main route. Its proximity does not establish continuity. The team must also distinguish its return direction from other branches and other teams' installations.

## Read the arrangement before naming the problem

At an already connected T-junction, branch selection remains necessary even though there is no physical break. Where separate guidelines must be connected, continuity needs attention as well. The length of a separation does not determine whether a transition is a jump or gap; the actual line arrangement matters.

For a classroom drawing, first identify what is connected, then identify the team’s return branch. State ownership and any local marker convention rather than inferring them from another team’s installation.

## Check understanding

Contrast the unresolved questions at an unmarked connected T-junction and at a separate branch line.

## Learning objective
Explain why a correct connection can still leave the wrong return decision.

## Compare entry and return
A diver makes a jump from the main line to a separate branch. On return, reaching the main line answers where the connection ends. It does not answer which direction on the main line leads to the team's entrance. Establish that reference during entry using the team's agreed navigation procedure.

Natural features and compass observations can help detect discrepancies. They do not replace the continuous guideline or justify taking an unverified exit. Other teams' equipment and unfamiliar markers must remain distinct from the team's own references.

## Reasoning task
Sketch a main line with two directions and one separate branch connected by a jump. Mark the team's verified return direction. Then remove that direction label: explain what information remains and what has been lost.
