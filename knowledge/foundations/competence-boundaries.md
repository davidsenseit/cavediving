# Competence is specific to the task

## Core idea

Certification records training; it does not prove readiness for every cave, configuration or task. Compare the intended dive with recently demonstrated skills and the team’s actual experience. An overhead removes the option of an immediate direct ascent.

## Original example

A familiar open-water buddy proposes entering a cave because both divers have redundant lights. Equipment does not supply the missing overhead training.
