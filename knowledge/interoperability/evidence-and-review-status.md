# Portable access needs honest evidence

## Core idea

The Markdown files and stable identifiers are usable without a particular AI provider. An assistant must actually read the relevant files and preserve draft status when explaining them. A URL or a successful file check is not evidence that another provider retrieved or interpreted the content correctly. Missing access must be reported.

## Original example

An assistant can read a catalog but not its linked knowledge file. It should describe that access boundary and ask for the needed content instead of presenting an imagined answer as repository-backed.
