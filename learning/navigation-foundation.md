# Navigation foundation

A starter learning path that illustrates the teaching format. It is not a complete navigation course.

1. Read [NAV-001](../knowledge/navigation/guideline-continuity.md).
2. Ask the learner to explain the value of a continuous, positively identified guideline in their own words.
3. Present [NAV-Q001](../questions/navigation/continuity.md) without the answer.
4. After their response, explain and discuss misconceptions.
5. Ask an **AI-generated practice** question with a materially different setting, checking the scenario against NAV-001.
6. Invite the learner to request a deeper explanation or select another topic.

No pass/fail classification is needed.
