## Delivery sequence

For each package: inventory concepts → verify independently → author original concise English Markdown → create original quiz questions → technical/safety/IP review → record reviewer and status → publish verified content.

Draft does not mean verified. Never upload third-party manuals or proprietary exam questions; independent reviewers must examine safety-critical claims. Keep supporting source documentation outside the published knowledge text, with lawful editorial records where needed.

### Release criteria

The knowledge base is complete only when every inventory subject is covered or explicitly excluded, its quiz coverage is indexed, safety-critical computations are independently validated, and relevant reviewers have approved the published content. The repository is currently private; a separate IP/publication review is required before changing visibility.
