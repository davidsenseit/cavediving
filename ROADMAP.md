# Cave Diving Knowledge Base — roadmap

This project is independently structured around diving concepts and learner needs. It does not replicate the sequence, wording, assessment questions or illustrations of any training publication.

Overall tracking: [Goal #1](https://github.com/davidsenseit/cavediving/issues/1).

## Process

1. Identify the knowledge required to understand a topic.
2. Validate factual claims and assumptions independently.
3. Create original, concise English learning material.
4. Create original questions and scenarios linked to stable concept IDs.
5. Review technical accuracy, safety and intellectual-property suitability.
6. Record actual review status and update the catalog.

Knowledge and questions not yet independently reviewed must remain marked `draft`. Only validated calculation utilities can be considered for operational planning, and every real dive requires trained human judgment, current site information and independent checks.

The tracker records work that can be continued in future sessions. It does not run work in the background.
