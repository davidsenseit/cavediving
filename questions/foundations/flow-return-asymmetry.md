# An easy entry can hide a demanding return

## Question

A hypothetical passage has water moving inward from the entrance. A team proposes estimating exit effort from how easy the inward swim feels. What is the key error?

## Choices

A. An inward current guarantees an equally easy outward swim.
B. The return may oppose the flow, changing time, effort and demand.
C. Current matters only for divers carrying cameras.
D. Any fixed gas fraction automatically accounts for all flow strengths.

## Answer and explanation

**B.** Assistance inward can become resistance outward. A assumes symmetry; C ties flow effects to an optional task; D treats an allocation as a validated demand model. Current conditions and team capability require assessment before using any estimate.
