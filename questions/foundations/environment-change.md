# Passage conditions review

## Teaching notes

- Learning objective: Explain how current direction affects the return journey.
- Level: Concept application
- Prerequisites: Inward and outward travel relative to the entrance; current; exit demand.

## Question

A fictional passage carries water from the entrance farther into the cave. The team plans to return along the same passage. Which change should it consider when estimating the return compared with the inward swim?

## Choices

A. The return may take longer, but the same distance means total gas use should remain unchanged.
B. The return may take longer and require more effort, so both duration and breathing demand need reassessment.
C. The return needs a higher breathing rate, but its duration can be copied from the inward swim.
D. The return can use the inward time and breathing rate if the team maintains the same finning technique.

## Answer and explanation

**B.** The inward swim is assisted by the current; the return opposes it. Progress over the ground and breathing demand can both change. A treats distance as a gas quantity, ignoring time and effort. C adjusts only one input. D assumes the same movement produces the same progress in opposite current directions. No current speed or team performance is supplied, so a numerical correction cannot be calculated.

## Follow-up discussion

Why would doubling the inward gas use be an unsupported estimate of total dive consumption?

### Tutor guidance

Look for rejection of assumed entry/exit symmetry: outward time and breathing demand need their own basis. Accept equivalent reasoning without requiring a specific numerical factor.
