# Breathing effort and workload application

## Teaching notes
Objective: apply the linked lesson to the stated observations. Teach its distinctions before assessment using a different example.

## Question

A return requires more physical effort than the outward swim. Cylinder pressure is still above the planned threshold. What assessment is justified?

## Choices

A. Assess breathing workload and return demand as well as remaining inventory.
B. Treat the original return estimate as unchanged until the threshold is reached.
C. Use the pressure reading as evidence that breathing effort is acceptable.
D. Assume the extra effort changes speed but cannot change breathing demand.

## Answer and explanation

**A.** Inventory and workload are different quantities. Extra effort can increase demand; pressure alone does not demonstrate that the breathing task or return estimate remains acceptable.

## Follow-up discussion

Why would an oxygen partial-pressure calculation alone not resolve this concern?

## Tutor guidance

It addresses oxygen exposure, not the whole breathing workload, ventilation or return demand.
