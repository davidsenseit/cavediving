# The first limit governs the team

## Question

The team reaches its agreed latest turnaround time: the deadline for ending penetration and starting the return. The plan allows time for the exit and contingencies after that deadline. Every diver is still above the agreed gas-turn threshold and the destination is close. What governs the decision?

## Choices

A. Continue for a few minutes because the unused gas allowance compensates for the time limit.
B. Continue until the gas-turn threshold is reached because it is a separate limit.
C. Begin the agreed exit response because an applicable limit has been reached.
D. Use the time reserved for exit contingencies to reach the destination before returning.

## Answer and explanation

**C.** Limits apply together; gas remaining does not cancel the agreed turnaround deadline. This deadline is not the maximum total dive time: the return must fit within the remaining plan. A and B let a gas allowance override a time limit; D spends contingency time on the optional objective.
