# A working backup does not restore the original plan

## Question

On a conventional open-circuit cave dive, a primary light fails and a backup is available. A teammate proposes continuing farther because the route is familiar. Which decision matches the repository’s stated boundary?

## Choices

A. End further penetration and follow the team’s trained exit response using backup lighting.
B. Continue until another light fails.
C. Continue if another diver lends the team a brighter beam.
D. Continue because familiarity replaces the failed primary.

## Answer and explanation

**A.** The backup supports the exit following the failure. B consumes another safety margin; C substitutes another diver’s illumination for the failed provision; D substitutes familiarity for equipment capability. The exact exit execution belongs to practical training.
