# Check contingency duration as well as operation

## Question

Before a proposed conventional open-circuit cave dive, a backup light turns on but its usable duration is unknown. The plan includes an extended exit contingency. What does the switch-on check establish?

## Choices

A. That the light covers every possible exit delay.
B. That it operates now, while duration and accessibility still need assessment against the plan.
C. That it can replace any primary light for the entire planned exposure.
D. That duration can be inferred from the number of lights packed.

## Answer and explanation

**B.** A brief function check does not measure endurance or usable access. A and C infer duration without evidence; D infers it from count. Verify the configuration and contingency provision before entry; a packed backup is not automatically a suitable backup.
