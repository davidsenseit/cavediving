# Evaluate a shared power failure

## Question

A classroom failure diagram has three lamp heads: two use battery pack X and one uses battery pack Y. All wiring from X fails together. What is the correct analysis of that one failure?

## Choices

A. All three lamps remain independent because each has a switch.
B. Two lamp heads still provide two surviving power sources.
C. Only the lamp supplied by Y remains powered.
D. The brightness of X prevents a common power failure.

## Answer and explanation

**C.** A shared power failure removes both X-fed heads. A and B count components instead of independent survival; D substitutes output for reliability. The remaining lamp count alone does not establish adequate equipment for a dive.
