# Depth control is not the whole position problem

## Question

During a supervised stationary task, a diver holds depth but clouds the floor whenever turning to communicate. Which observation best identifies what needs work?

## Choices

A. The depth trace proves all position-control skills are adequate.
B. Sediment disturbance can be ignored when the depth is constant.
C. More task complexity will automatically improve control.
D. Orientation, movement and task loading need attention despite stable depth.

## Answer and explanation

**D.** Depth balance does not establish good trim, low-impact movement or spare attention. A and B mistake one measurement for the whole skill; C assumes added workload is corrective. Use suitable supervised practice rather than judging control from depth alone.
