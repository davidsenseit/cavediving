# A packing list is not a functional check practice

## Question

A diver wants to interpret technical-mode settings. The available documentation covers recreational mode and a different firmware version; the installed version has not been recorded.

What should an assistant do before giving mode-specific configuration advice?

## Choices

A. Assume the newest attached version is installed.
B. Confirm the installed firmware and mode and use matching documentation.
C. Apply a recreational manual to every technical mode.
D. Infer configuration from the computer’s brand.

## Answer and explanation

**B.** Version, mode and matching instructions are necessary context. Attached release notes do not prove an update occurred. Do not invent menu steps when the relevant documentation is missing.
