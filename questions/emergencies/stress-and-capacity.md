# Plan around reduced capacity practice

## Question

A team can explain an equipment-failure response in a briefing, but no one can recall having practiced it in the planned configuration.

Which evidence would most directly address the capability gap?

## Choices

A. A successful drill in an earlier configuration with different equipment access.
B. Correct identification of the response in a written scenario.
C. Recent supervised performance of the relevant skill in that configuration.
D. An individual function check of each component before entry.

## Answer and explanation

**C.** Recent supervised performance addresses execution in the relevant configuration. A may not transfer when access changes. B demonstrates recognition. D checks components but not the coordinated response. None guarantees success in a real failure.

## Follow-up discussion
Which change in equipment or conditions would make you reassess the value of an earlier drill?

## Tutor guidance
Accept changes affecting access, communication, mobility or position control. Ask the learner to explain the mechanism, rather than merely naming an item.
