# Separate a familiar description from demonstrated skill

## Question

A diver can describe a response fluently but has never practiced it in the configuration proposed for the next cave dive. What evidence is missing?

## Choices

A. A longer written explanation from an AI.
B. A promise that equipment access will be easy.
C. Demonstrated practical ability with the relevant equipment under appropriate supervision.
D. A quiz pass confirming the procedure can be recalled.

## Answer and explanation

**C.** Being able to explain a task does not demonstrate its execution. A and D add descriptive evidence only; B replaces an access check with confidence. Address the capability gap through suitable training rather than discovering it during a real emergency.
