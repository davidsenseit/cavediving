# A connector does not decide the return branch

## Question

In a tabletop route review, a temporary connector joins two lines, but the drawing does not identify the return branch at the resulting junction. What does the connector alone establish?

## Choices

A. That either return branch reaches the team’s exit.
B. That markers no longer need context.
C. A physical connection, without resolving which branch leads to the team’s exit.
D. That the destination of the second line has been verified.

## Answer and explanation

**C.** Continuity and route selection are distinct questions. A assumes equivalent branches; B discards identification; D treats a connection as destination evidence. A complete route review must establish both continuity and an unambiguous way back.
