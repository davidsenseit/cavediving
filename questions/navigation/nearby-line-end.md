# Visibility is not a connection

## Question

An optional branch begins across a clearly visible patch of open passage with no line linking it to the team’s route. A diver argues that excellent visibility makes this equivalent to a physical connection. Why is that reasoning unsound?

## Choices

A. Visibility can change, and visual proximity does not create continuous line reference.
B. A wider beam would turn the visible gap into a continuous line.
C. A photograph of the gap supplies an underwater tactile reference.
D. Only the entry direction needs a physical reference.

## Answer and explanation

**A.** The route must remain meaningful when the view changes. B confuses illumination with connection; C confuses a record with a physical reference; D ignores the return. This question does not teach connection placement or authorize a branch dive.
